# Yume Haze Zapret

Удобная программа для Windows, которая объединяет в одном окне
[zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube) и
[tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy) от **Flowseal**.

**[⬇ Скачать установщик (Releases)](https://github.com/Deraspik/YumeHaze-Zapret-ZapreTYZ/releases/latest)**

![Главная](screenshots/home.png)

> Внутри уже лежат **zapret 1.10.4** (ALT11–ALT13, FAKE TLS AUTO ALT2/ALT3, EXP) и
> **tg-ws-proxy 1.11.4** — после установки ничего докачивать не нужно.

## Что нового в 2.1

**Новый интерфейс.** Тёмная палитра Discord (`#313338` / `#2b2d31` / `#1e1f22`, акцент `#5865f2`) —
окно программы и Discord рядом смотрятся как одно семейство, но компоновка своя:

- слева узкий рейл с разделами вместо верхних вкладок;
- каждый раздел — одно полотно, сверху полоска-оглавление: клик плавно прокручивает
  к блоку, активный пункт подсвечивается при скролле, полоска закреплена под шапкой;
- иконки — обычные линейные, шапка показывает версию и состояние обхода;
- темы: тёмная, светлая, AMOLED; 9 акцентов; скругление и масштаб интерфейса.

**Обновления починены.**

- Свои списки (`*user*.txt`), игровой фильтр, исключения и импортированные `.bat`-стратегии
  больше **не стираются** при обновлении zapret.
- Установка идёт в временную папку и только потом подменяет компонент — битый архив
  не ломает рабочую версию. Перед обновлением делается резервная копия (последние 3 — в `%APPDATA%\Yume Haze Zapret\backups`).
- Служба останавливается на время обновления и поднимается уже на новой версии; если выбранная
  стратегия исчезла из релиза, программа сама переключится на `general.bat`.
- Проверка и установка работают через зеркала GitHub (без VPN), есть автообновление при запуске
  и раз в 6 часов, кеш списка версий и текст «Что нового».
- TG WS Proxy обновляется из архива тега (а не из exe-ассетов), `__pycache__` вычищается.

Остальное: игровой режим, авто-восстановление состояния, избранные стратегии, история тестов,
свои сайты и исключения, DNS в один клик, блокировка рекламы (hosts), «Починить Discord»,
проверка любого сайта, консоль с фильтрами и экспортом, работа из трея, полный английский интерфейс.

## Возможности

- **Zapret** включается одним переключателем, есть выбор стратегии. Работает как служба Windows
  и сам запускается при старте системы — окно программы держать открытым не нужно.
- **TG WS Proxy** — локальный прокси, который открывает Telegram без VPN.
- Быстрый тест подключения, подбор стратегии по `targets.txt`, игровой фильтр, IPSet, hosts, диагностика.
- Компоненты обновляются с GitHub, есть консоль и работа из трея.

## Управление

| Где | Что делает |
|---|---|
| Рейл слева | переход между разделами |
| Оглавление под шапкой | прокрутка к блоку раздела |
| Шапка: «Проверить» | проверка обновлений компонентов |
| Шапка: «Тест» | быстрый тест подключения |
| ПКМ по иконке в трее | включить/выключить Zapret и прокси, стратегия, тест, консоль, выход |

## Портативная версия (без установки)

`YumeHazeZapret-portable.zip` (29 МБ) — распаковал и запустил, установщик не нужен:

- `Yume-Haze-Zapret-portable.bat` — обычный запуск (запросит права администратора, они нужны WinDivert);
- `Yume-Haze-Zapret-portable-console.bat` — то же с консолью, видно ошибки, если что-то не стартует;
- настройки, бэкапы и логи лежат в папке `data` рядом с программой — папку можно целиком
  переносить на флешке, профиль Windows не засоряется.

Внутри: embeddable Python 3.12 + PySide6 (только Core/Gui/Widgets/Svg) + `app/` +
`components/` с zapret 1.10.4 и tg-ws-proxy 1.11.4. Пересобрать в любой момент:

```
python packaging/fetch_components.py
python packaging/make_portable.py --zip
```

## Где взять установщик

Готовый `.exe` собирается только на Windows — из исходников его не получить на Linux/macOS.

**Вариант 0 — ничего не собирать:** возьмите `Yume Haze Zapret.exe` (29 МБ) из раздела Releases.
Это один файл: скачал → запустил → работает. Внутри уже есть Python, PySide6, zapret 1.10.4
и tg-ws-proxy 1.11.4, поэтому ставить ничего не надо. При первом запуске рядом с exe
появится папка `components\` — там zapret и прокси, их можно править руками.
Консольных окон нет: приложение собрано PyInstaller-ом в режиме GUI (`console=False`).

**Вариант 1 — своими руками (Windows):** Python 3.12 + Inno Setup 6, затем `build.bat`.
Скрипт скачает zapret 1.10.4 и tg-ws-proxy 1.11.4 в `components/`, соберёт программу
через PyInstaller и упакует установщик в `release\YumeHazeZapret_Setup_2.1.0.exe`.
Нужны другие версии — задайте `ZAPRET_TAG` / `TG_TAG` перед запуском.

**Вариант 2 — без Windows вообще:** залейте репозиторий на GitHub, откройте
**Actions → Build Yume Haze Zapret → Run workflow** и дождитесь артефактов:

- `YumeHazeZapret_Setup` — установщик (`YumeHazeZapret_Setup_2.1.0.exe`);
- `YumeHazeZapret_portable` — та же программа без установщика (папка `dist\Yume Haze Zapret`).

Пуш тега `v2.1.0` дополнительно прикрепляет установщик к GitHub Release.

**Вариант 3 — собрать .exe на Linux (так собран релизный):**
```
bash packaging/build_exe_wine.sh          # → dist\Yume Haze Zapret.exe, один файл
bash packaging/build_installer_linux.sh   # опционально: установщик Inno Setup
```
Скрипт ставит wine + Inno Setup 6.7.4, компилирует запускатор `Yume Haze Zapret.exe` (C + иконка +
манифест администратора), собирает раскладку и вызывает `ISCC.exe` под wine.

## Структура

| Путь | Что внутри |
|---|---|
| `app/main.py` | точка входа (режим `--tgproxy` — встроенный TG WS Proxy) |
| `app/core.py` | служба Zapret, TG-прокси, обновления, автозапуск |
| `app/ui.py` | интерфейс: рейл, шапка, оглавление, все разделы |
| `app/ui_theme.py` | палитры (dark/light/amoled), акценты, сборка QSS |
| `app/features.py` | списки, hosts, DNS, трей-логика, резервные копии |
| `app/zapret_tools.py` | диагностика, тесты стратегий |
| `packaging/fetch_components.py` | загрузка zapret и tg-ws-proxy в сборку |
| `packaging/` | PyInstaller spec, Inno Setup |

Настройки хранятся в `%APPDATA%\Yume Haze Zapret`.
